### Fixes

- **Close a Todo from its detail view.** Open a task and use the visible Close issue action without returning to the list. Confirmation explains that this closes the GitHub issue while keeping its project status unchanged.
- Failed closures keep the task and your comment draft available so you can retry. Successful closures update the detail view and task lists immediately, including during GitHub's search indexing delay.

### Install

Existing installs receive this update automatically. To update manually, download `GitHub.Tasks_0.7.1_universal.dmg` on macOS or the Windows/Linux package for your platform. Your sources, token, and settings carry over.
