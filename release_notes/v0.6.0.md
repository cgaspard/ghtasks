### New

- **Triage the Inbox in bulk.** Hover any notification and a checkbox appears in the gutter. Tick a few, and a bar slides in above the list with a running count and a single **Mark as read** — one action instead of hunting down each row's checkmark. Selection is keyboard-reachable too: tab onto a checkbox and hit Space.
- **Mark all read.** The same bar carries a **Mark all read** button whenever anything is unread. With no filter applied it clears your *entire* GitHub notification inbox in a single request — including threads this app never loaded — exactly like the button on github.com/notifications. It takes two clicks: the first arms it, the second confirms. Nothing is sent until you confirm.
- **Under a filter, it stays honest.** With a category, "Unread only", or a search active, the button reads **Mark 7 read** and touches only those seven. It never quietly means something broader than what you can see.

### Notes

- Marking read always reaches GitHub. The Inbox is a mirror of github.com/notifications, not a local dismissal list, so anything you clear here is cleared everywhere — and **it can't be undone from this app.** That's why "Mark all read" asks twice.
- If a mark-read request fails, the affected rows flip back to unread rather than leaving the list showing a state GitHub never accepted.
- Bulk requests are paced to stay inside GitHub's rate limits, so clearing a large selection won't knock out the next background refresh.

### Install

Download `GitHub.Tasks_universal.dmg` (signed + notarized), open it, and drag GitHub Tasks to Applications. Existing installs update themselves — your sources, token, and settings carry over.
