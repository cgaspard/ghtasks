### New

- **Choose Compact or Expanded cards.** Each tab remembers its own layout. Compact Projects groups single-line issues into status buckets with their project colors and item counts. Expanded Projects keeps the familiar cards, colored status stripes, labels, milestones, and linked pull requests.
- **Check off Todos with confidence.** A Todo checkbox asks before closing the issue on GitHub. Cancel or press Escape to leave it open. Closing an issue keeps its project status unchanged.
- **Settings has focused pages.** Open the gear for Projects & repositories, Appearance, Notifications, General, or About & updates. Preferences save automatically with visible feedback; connection edits have explicit Save and Cancel actions.
- **Keep new-issue drafts.** Choose a repository first, optionally add a project, and return to an unfinished draft later. Titles, descriptions, template form answers, and labels survive closing the composer or restarting the app. Discard clears the draft, and successful creation offers a direct way to view the issue.

### Changed

- **A clearer app toolbar.** Navigation, Settings, and your account menu stay at the top. Sync status and Refresh now sit at the bottom, where they stay visible while your task list scrolls.
- **Easier connection setup.** Repository search presets provide a starting point, with advanced queries available when needed. Pause a connection without deleting it, and confirm before removing one.
- **Appearance controls explain their purpose.** Window height, list density, and card layout have separate controls. Settings remains scrollable in the compact window.

### Fixes

- Saved refresh intervals now change the running refresh schedule. Late pages from an older project refresh cannot replace newer results.
- Failed issue closures, status changes, and Inbox read actions retain or restore the previous state and show a recoverable error. Inbox sync failures keep loaded notifications visible and never claim the Inbox is empty.
- Load older Inbox notifications while filtering, with feedback for loading and retrying. Task attention cues correctly match their GitHub notification threads.
- Dropdowns stay inside the window, keyboard focus returns after actions, and sign-in failures offer a new code or a way to cancel.

### Install

Download `GitHub.Tasks_0.7.0_universal.dmg` (signed + notarized), open it, and drag GitHub Tasks to Applications. Existing installs update themselves, and your sources, token, and settings carry over. Windows and Linux installers and packages are available in the release assets below.
